# Resmi Miyav Çevirmeni

Bu depo, kedi seslerinin Türk kamu yazışma üsulüne dönüştürülmesi için kurulmuş **uluslararası çapta öncü** bir girişimdir.

Hayır, şaka değil. Belki biraz şaka. Ama evrak ciddi.

## Neden var?

Çünkü bir kedi "miyav" dediğinde bu, aslında çoğu zaman:

anlamına gelir. Bilim bunu henüz kabul etmedi; biz ettik.

```bash
python3 cevirmen.py miyav
python3 cevirmen.py miyav miyav

```
